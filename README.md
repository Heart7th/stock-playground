# 股市游乐场 · 炒股小游戏玩法原型

在线试玩：https://heart7th.github.io/stock-playground/

四个炒股主题的手机小游戏原型，竖屏单手玩：

- ① 按住别松手：按住满仓、松开空仓，45 秒一个交易日。涨停买不进，跌停卖不掉。还有「大A模式」（T+1；下单时按住，行情暂停，按得越久仓位越大，满仓之后是融资）和「操盘手」（简单 / 普通 / 困难：盘中随时多空、调杠杆，困难没有涨跌停）：每天三只股票选一只（选股页可切“简洁 / 专业”），5 天一关，第 1 关由搭档手把手引导；超出目标的钱进存钱罐，可以买道具、锦囊、退关保命；战法会越练越强，还有四选一的陪伴搭档。卡通圆润画风。
- ④ 画出明天：看一段真实的历史指数行情，用手指画出未来 20 天，揭晓后打分。
- ⑤ 解套大作战：开局就在山顶站岗，拖动挂单线高抛低吸，把成本做到现价以下。第 1 关是 5 步新手教学。
- ⑧ 谁是接盘侠：一群人炒同一只股票，买就推高、卖就砸低。喊单、抢跑、揪庄家，收盘还拿着的人按次日开盘价结算。房间 3–12 人，可以让人中途进场。联机房间（内测）需要配套的 bag-server.cjs 服务器，这个公开页面上只能玩单机。

这里只有打包好的静态页面（单文件 HTML，零外部依赖、离线可玩）、图标和分享图，由项目里的 `tools/deploy-gh.mjs` 自动发布。公司全部虚构，④ 的题目来自真实历史指数行情；成绩只存在本机浏览器里。仅供娱乐，不构成投资建议。
